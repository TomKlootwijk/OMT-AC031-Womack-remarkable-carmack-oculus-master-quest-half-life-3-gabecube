Generation —

Mirage changes only the drawn glyph. Node identity, coordinates, occupancy and logs are unchanged. For Klein mode this is a chart illustration, not an embedding of the Klein bottle.

Author: Tom Klootwijk. Original procedural glyphs; no C&C or Tolkien artwork, text or game assets. The “ring” is a presentation motif, not CPU ring 0.
