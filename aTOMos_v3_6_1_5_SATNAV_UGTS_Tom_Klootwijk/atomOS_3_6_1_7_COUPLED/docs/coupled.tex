\section{The completed geometry--state feedback connection}
\label{sec:coupled}
Version 3.6.1.7 defines and implements \textbf{CGK-R1}, a coupled continuous and
discrete state kernel. Prepared GNSS observations are solved by SATNAV-R1. Their
unquantized position estimates become inputs to a persistent modeled mechanical
state. Geometry of that state is encoded into the literal ASA/NA and J--K word
operations. Their result changes the mechanical operator, and the advanced
position supplies geometry for the following step.

\begin{panel}
\textbf{The complete executed dependency}\par
Corrected-code observations $\to$ SATNAV ECEF estimate $\to$ local target $z_n$
$\to$ geometry of the carried state $p_{n-1}$ $\to$ predicate words
$\to$ editable drive/X/J/K equations $\to$ $q_n$
$\to$ stiffness and force $\to$ $(p_n,v_n)$ $\to$ next geometry.\par
The actual UGTS handoff publishes the carried J/K state and both the original
measurement estimate and the modeled physical state.
\end{panel}

The source did not supply complete M2 circle-plus, predicate-encoder or physical
eigenmatrix definitions. This release supplies explicit new definitions for all
three roles. Their equations, input parameters, units and execution order are
given here and in \code{docs/COUPLED\_CONTRACT.md}. They are new formalizations
using the retained primitives, not claims of reconstructing unavailable text.

\subsection{State, observations and time identity}
For each independently seeded trajectory, retain
\begin{equation}
S=(p,v,q,\phi,t,\rho_{\rm prev},\theta_{\rm prev},\chi_{\rm prev}),
\end{equation}
where $p\in\R^3$ is ENU position in metres, $v\in\R^3$ is velocity in m/s,
$q$ is a 32-bit word, $\phi$ is the separate hoop phase, $t$ is full unwrapped
time and $\chi_{\rm prev}$ records whether the previous chart exists. Satellite
geometry, clock bias, formal covariance and original observation identity remain
available in the measurement record outside this state and its compact keys.

Sample $n$ supplies time $t_n$, target $z_n$, observation validity $o_n\in\{0,1\}$,
and external force $f_n$. Define $\Delta t=t_n-t_{n-1}>0$. Predicates read the
old state together with the endpoint observation. The observed target and force
are the piecewise constant inputs of the declared discrete observer interval;
the resulting mechanical state is labeled $t_n$. The trace records both interval
endpoints, and input rows are never silently reordered.

For a solved ECEF position $\hat r_n$, the fixed ENU transform gives
\begin{equation}
z_n=R_{\rm ENU}(\hat r_n-r_0^{\rm ECEF}).
\end{equation}
The modeled position $p_n$ is a separate quantity. It is not substituted into the
original receiver solution or represented as another independent GNSS measurement.

\section{Literal chart motion and an explicit circle-plus}
For the old modeled position $p=(E,N,U)$, set $r=\sqrt{E^2+N^2}$. For
$r\ge r_{\rm core}>0$, use the retained chart
\begin{equation}
\rho=\log(r/r_0),\qquad \theta=\operatorname{atan2}(N,E).
\end{equation}
The preceding chart belongs to the preceding step's \emph{before} state. Thus
the next step compares the newly advanced physical geometry with the geometry
that produced that advance. The first step has no chart increment.

For two defined charts, set
\begin{equation}
\Delta\theta=\wrap(\theta-\theta_{\rm prev}),\qquad
\Delta\rho=\rho-\rho_{\rm prev},\qquad
\alpha=\arctan(\Delta\theta/\Delta\rho)-a_0.
\end{equation}
This is literal source OTAN2. A zero pair, zero denominator, missing chart or
floating-point range failure retains its explicit status. It is never replaced
by quadrant-resolving \code{atan2} while keeping the source name.

\subsection{CGK-R1 circle-plus definition}
Let $\wrap:\R\to[-\pi,\pi)$, with the $\pi$ tie represented by $-\pi$. For
$0\le w\le1$, define
\begin{equation}
a\mathbin{\oplus_w}b:=\wrap\!\left(a+w\wrap(b-a)\right).
\label{eq:circleplus}
\end{equation}
This is interpolation along the selected shortest angular arc. It is not Boolean
XOR, and associativity is not assumed. At $w=0$ it selects $\wrap(a)$; at $w=1$
it selects $\wrap(b)$. Common full-turn changes in either input do not change
the selected phase, subject to the declared tie convention.

With $e=z_n-p$, the target bearing $\beta=\operatorname{atan2}(e_N,e_E)$ exists
when $o_n=1$ and the horizontal error is at least $r_{\rm core}$. The actual
blended phase used by the encoder is
\begin{equation}
\psi=\wrap\!\left(\beta\mathbin{\oplus_w}\alpha+\phi\right).
\end{equation}
Both angular inputs must be defined. If they are not, only the alignment
predicate is false. Limit, fringe, support, editable Boolean equations and the
physical step still evaluate according to their definitions.

\subsection{Independent hoop evolution}
The hoop has its own supplied angular rate $\omega_h$ and evolves as
\begin{equation}
\phi_n=\wrap(\phi_{n-1}+\Delta t\,\omega_h).
\end{equation}
Its role stays distinct from geodetic latitude, modeled chart angle and full
time winding. It enters the blend explicitly and is preserved in the key tuple.

\section{The geometry-to-bit encoders}
Each present channel $i$ supplies a unit mechanical direction $u_i$, angle center
$\beta_i$, alignment tolerance $\epsilon_i$, projected-error limit $L_i$,
support geometry and fringe width $\eta_i$. Parameters and their units are input
data; changing them changes the executed model.

For a sphere with center $c_i$ and radius $R_i$,
\begin{equation}
s_i(p)=\|p-c_i\|-R_i.
\end{equation}
A channel may instead select the inherited finite-cone signed-distance function:
reduce the point to axial/radial coordinates and take the signed distance to its
closed triangular meridian. Slant length, half-angle, apex and unit axis are
supplied explicitly. The cone definition is the same one given later in this
volume; it is evaluated on the evolving modeled position.

The four Boolean features are exactly
\begin{align}
A_i^{\rm geom}&=[\psi\ \text{defined}]\land
 [|\wrap(\psi-\beta_i)|\le\epsilon_i],\\
L_i^{\rm geom}&=[o_n=1]\land[|u_i^Te|>L_i],\\
F_i^{\rm geom}&=[|s_i(p)|\le\eta_i],\\
S_i^{\rm geom}&=[s_i(p)\le0].
\end{align}
Channel $i$ occupies bit $i$; absent channels contribute zero. The resulting
words are named \code{align}, \code{limit}, \code{fringe} and \code{support}.
The separate \code{valid} word is all ones for a valid sample and zero otherwise.

\subsection{Four actual input equations}
The editable JSON supplies drive, input, J and K expressions. The default handoff profile uses
\begin{lstlisting}
"equations": {
  "d": "limit | fringe",
  "x": "(q | d) & support",
  "j": "y & (limit | fringe)",
  "k": "align & ~limit & ~fringe"
}
\end{lstlisting}
The vocabulary is the exact Boolean algebra \code{\&}, \code{|},
\code{\textasciicircum}, \code{\textasciitilde}, parentheses and word constants
\code{0}/\code{1}. All expressions read the old $q$. The drive sees six inputs,
X sees those plus drive, and J/K additionally see the ASA output $y$. The compiler
enumerates their exact 64-, 128- and 256-bit truth tables. The direct Python
reference evaluates the original expression trees rather than these tables.

The source ASA masks and whole-word boundary operation then produce
\begin{equation}
a=x\land A\land V,\quad n=a\land N,\quad h=\pop(n\land B),\quad
y=\begin{cases}0&h>0,\\n&h=0,\end{cases}
\end{equation}
followed by the synchronous literal update
\begin{equation}
q_n=\big[(J\land\neg q_{n-1})\lor(\neg K\land q_{n-1})\big]\land V.
\end{equation}
Absorption determines $y$; it does not override the supplied J/K equations.

\section{The physical operator supplied by the feedback state}
The modeled dynamics have diagonal positive mass $M$, diagonal damping $C$,
and a supplied symmetric base stiffness $K_0$. For each present channel,
\begin{align}
\kappa_i(q_i)&=\kappa_i^{\rm off}
 +(\kappa_i^{\rm on}-\kappa_i^{\rm off})q_i,\\
g_i(q_i)&=g_i^{\rm off}+(g_i^{\rm on}-g_i^{\rm off})q_i,\\
K(q)&=K_0+\sum_{i\in V}\kappa_i(q_i)u_i u_i^T,\\
F(q)&=f_n+\sum_{i\in V}g_i(q_i)u_i.
\end{align}
Mass entries are kilograms, damping entries kg/s, stiffness entries N/m and force
entries newtons. Directions are dimensionless. Signed stiffness and damping
are accepted; they can represent an active or unstable model and are reported
without silently clipping them to a passive case.

The declared equation of motion over this sample interval is
\begin{equation}
M\ddot p+C\dot p+o_nK(q_n)(p-z_n)=F(q_n).
\label{eq:coupled-mechanics}
\end{equation}
The newly committed word therefore changes a physical operator, not just an
annotation on an independently calculated trajectory. On an unavailable observation,
$o_n=0$ removes the target spring term. The discrete equations, external force,
state-dependent force and velocity evolution continue.

\subsection{A complete discrete advance}
Backward Euler gives the actual linear system solved at every step:
\begin{align}
G&=M+\Delta t\,C+\Delta t^2 o_nK(q_n),\\
b&=Mv_{n-1}+\Delta t\,[F(q_n)+o_nK(q_n)(z_n-p_{n-1})],\\
v_n&=G^{-1}b,\qquad p_n=p_{n-1}+\Delta t\,v_n.
\end{align}
The implementation solves the three-dimensional system with pivoting; it does not
form an inverse as its numerical algorithm. The independent reference uses a
separate numerical linear solver. Every matrix entry, right-hand side, before
state and after state is retained in the trace.

For signed coefficients $G$ can become singular. This is an explicit numerical
failure, not a valid state advance. The computed $q_n$ remains recorded; the
mechanical state and its valid time stay unchanged. Later rows of that trajectory
carry a previous-failure status, while other trajectories continue. Nonfinite
diagnostic components are represented as null only on failure records.

\section{The physical eigenmatrix and mechanical checks}
Because $M$ is positive diagonal and $K$ symmetric, define
\begin{equation}
D(q)=M^{-1/2}K(q)M^{-1/2}.
\label{eq:physical-eigenmatrix}
\end{equation}
This is the explicit CGK-R1 physical eigenmatrix. It is distinct from the
SATNAV observation Jacobian. The native code computes its sorted real eigenvalues
and orthonormal eigenvectors, retaining $D$, $K$, eigenvectors and a residual.
Upper-triangle construction is mirrored to maintain exact floating-point symmetry.
The native Jacobi solver scales by the largest matrix entry and uses a pair-relative
$2\times10^{-15}$ off-diagonal criterion with at most 64 rotations, preserving
small independent modes in matrices with widely separated stiffness scales.

If $Dw_j=\lambda_jw_j$ and $\varphi_j=M^{-1/2}w_j$, then
\begin{equation}
K\varphi_j=\lambda_j M\varphi_j,\qquad
w_i^Tw_j=\delta_{ij}.
\end{equation}
For $\lambda_j>0$ the undamped natural angular frequency is
$\sqrt{\lambda_j}$ rad/s. For $\lambda_j<0$, $\sqrt{-\lambda_j}$ is the
undamped modal growth rate; a negative value is not reported as a real oscillation
frequency. Zero eigenvalues represent neutral stiffness modes. Damping can change
the actual transient growth or decay; these are stiffness-mode quantities.

The recorded eigensystem residual is
\begin{equation}
r_\lambda=\max_{a,j}|(DW-W\operatorname{diag}\lambda)_{aj}|.
\end{equation}
Verification also checks orthonormality and the independently computed spectrum.
Signs of eigenvectors and the choice of basis inside repeated eigenspaces are not
used as correctness criteria.

\subsection{What stability can actually be proved}
For a fixed target, zero force, fixed $q$, $o_n=1$, $C\succeq0$ and $K\succeq0$,
let $E=\tfrac12v^TMv+\tfrac12(p-z)^TK(p-z)$. The implemented backward-Euler step
satisfies
\begin{align}
E_n-E_{n-1}={}&-\Delta t\,v_n^TCv_n
-\tfrac12(v_n-v_{n-1})^TM(v_n-v_{n-1})\nonumber\\
&-\tfrac12(p_n-p_{n-1})^TK(p_n-p_{n-1})\le0.
\end{align}
This follows by substituting the discrete equation and the quadratic difference
identity. A changed word changes $K$ and can change stored potential energy;
signed coefficients, external forces and moving observations are also outside
this fixed-operator inequality. No general convergence claim is substituted for
those actual dynamics.

\section{Actual SATNAV/UGTS handoff and editable model input}
The updated \code{tools/ugts\_handoff.py} invokes the coupled profile by default.
It consumes the actual solution and profile files, creates the coupled model input,
executes the native backend and independently replays its complete trace. The
earlier hold-only behavior is available explicitly as \code{--legacy-hold}.

Each published record retains the original solver result and a separately labeled
modeled state. J/K before, input values and after now come from the executed
recurrence. The modeled ENU state is transformed back to ECEF for publication,
and its local chart feeds both original 64-bit codecs. Full time, winding, Up,
clock bias and original formal covariance remain outside the compact addresses.
Failed and unavailable observation rows retain their identity and lineage.

\subsection{Inputs are inspectable and editable}
\code{examples/coupled/model.json} declares version \code{3.6.1.7}, profile
\code{CGK-R1}, the four Boolean equations and a list of trajectories. Each
trajectory defines initial time/position/velocity/word/phase, mass, damping, base
stiffness, chart and hoop parameters, masks, channel geometries and timed samples.
Sphere and cone supports, on/off force and stiffness, directional encoders and
the observation sequence are all supplied as data. No geometric-to-bit encoder
or physical coefficient is silently inferred from a name.

The native compiler writes four exact CSV schemas: trajectory manifest, channels,
samples and equation truth tables. Their order and field meanings are specified
in \code{COUPLED\_CONTRACT.md}. The resulting trace has one row per sample,
including full geometry, predicate words, ASA tuple, J/K operands, physical
matrices, eigensystem and state advance. Hashes bind the supplied model and trace.

\subsection{Run the complete connection}
From the package directory, using the delivered Windows binaries:
\begin{lstlisting}
bin/windows/cpu/satnav.exe --input examples/demo \
  --out results/my_satnav --backend cpu --verify
python tools/ugts_handoff.py --input examples/demo \
  --run results/my_satnav --backend cpu
\end{lstlisting}
The coupled tool also runs a directly supplied model:
\begin{lstlisting}
python tools/coupled.py --input examples/coupled/model.json \
  --out results/my_coupled \
  --binary bin/windows/cuda/coupled_kernel.exe --backend cuda
\end{lstlisting}
Output directories are new for each run. A CUDA thread owns one complete
trajectory; it advances that trajectory in time order. Parallelism spans independent
trajectories and does not break the carried dependence within a trajectory.
