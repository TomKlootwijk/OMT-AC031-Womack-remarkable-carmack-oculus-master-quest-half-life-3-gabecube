\section*{From retained equations to a native execution profile}
\addcontentsline{toc}{section}{From retained equations to a native execution profile}
R15 makes the hinge construction executable in explicit domains. Its exact
reference carries $a+b\phi$ values, literal sequential expressions, typed
guards, ordered ASA/NA masks and atomic JK updates. The chart record keeps
both orientation and complete winding information. Integer words retain the
entire seed; a display or geometric cache does not replace it.

The native implementation uses CUDA allocations, integer texture objects,
unfiltered indexed fetches and kernels over persistent device storage. In this
release, ``bare metal'' names this direct native programming level. CUDA still
uses its driver and the operating system. Hardware controls cache replacement;
the program does not guarantee that an entire expanded working set stays in
texture cache.

An exact binary64 seed is an exact finite mathematical input. It is not an
exact measurement of a physical direction. The spherical comparison fixes
the same input words for S2 and aTOMos. The hybrid ID-list path uses the same
robust predicate for final membership after conservative CUDA filtering.
The resident count path adds a proved binary64 interval: definite decisions
remain on the GPU, and unresolved queries have an explicit complete host
resolution path. A complete count and a complete list of identities are
different outputs and have separate comparisons.

Immutable query alternatives can be selected by the old device state. A
following kernel commits the resolved count's ASA/NA and JK transition before
the next selection. A separate integer working-set profile feeds old words
into bounded $\phi$ operators and ordered masks across complete device epochs.
Its banked sweep visits every declared record and compares immutable texture
fetches with ordinary loads while using the same global state buffers.

The performance experiment distinguishes single queries, batches, data
distributions, CPU thread counts, GPU kernel time and complete host-visible
time. A spherical radius-query result does not establish parity with S2's
polygon operations, region covering or full library. Texture and ordinary
global-memory reads are measured separately on matched CUDA bodies. Count
query results, ID-list results and word-feedback memory sweeps retain their
own output contracts, timing boundaries and validation evidence.

\subsection*{Lineage and evidence}
The complete R14 mathematical field foundation and operator catalog are
retained in the later chapters and appendix, with their original scientific
sources. The new native profiles are explicitly smaller executable subsets;
an inherited catalog entry is not evidence that the GPU evaluates it.
The latched NIST packet remains the same immutable source observation.
No new continuous atomic-clock synchronization is implied.

R15 correctness checks and matched S2 benchmarks were explicitly authorized.
Their recorded inputs, configuration, measurements and limitations accompany
the manuscript. Document rendering verifies the artifact, while runtime checks
exercise the stated implementation. Neither substitutes for physical device
validation. Author attribution is supplied by Tom Klootwijk; external laws,
CUDA and official S2 retain their own provenance and licensing.
