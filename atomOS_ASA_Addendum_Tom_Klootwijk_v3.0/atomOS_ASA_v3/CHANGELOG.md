# 3.0.0 — ASA addendum

Standalone addendum module for paired aperture image sampling, explicit NA gating, profile L1 lens lookup, linear/Morton8 storage and texture/global CUDA comparison. Added independent Python arithmetic, a rational 250/128 Hz schedule, per-record seals, fail-fast memory budgets and Codex review instructions.

This version does not embed the entire previous branching/RK4/universal-machine package. It exports a coordinate-sample API to which a base engine can connect.
