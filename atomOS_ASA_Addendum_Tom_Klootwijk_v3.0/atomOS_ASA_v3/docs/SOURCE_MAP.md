**B:** `TOM KLOOTWIJK fly's-have-interesting-eyes-how-do-they-work(1).pdf` — 8 pages.
Hashes and page counts are in `source/manifest.json`. Page references use PDF page order.

The supplied transcripts also contain weapon-release, surveillance and named-person targeting routines. Those routines are excluded, not reinterpreted as working software. Their omitted interfaces are not needed by the numerical image operator.

## Missing numerical data in the sources
The sources do not provide a unique liquid-lens transfer function, lens coefficients, complete CUDA descriptors, exact tile dimensions, a scalar image-reduction rule or a memory budget. `docs/PROFILES.md` lists each assigned choice rather than presenting these as verbatim source equations.
