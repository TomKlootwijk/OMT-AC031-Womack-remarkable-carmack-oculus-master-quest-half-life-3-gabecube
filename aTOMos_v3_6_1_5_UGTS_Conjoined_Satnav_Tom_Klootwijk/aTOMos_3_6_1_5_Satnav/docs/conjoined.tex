\section*{Release definition}
\addcontentsline{toc}{section}{Release definition}
\textbf{aTOMos v3.6.1.5 is the satellite-positioning specialization of the conjoined aTOMos and UGTS engine.}
The aTOMos word/state contract and UGTS geometric/packing contract are joined in one input, evaluation and
result sequence. The navigation equations are a new, explicitly named profile: \textbf{SN1}.

\subsection*{Build and execution status}
The CPU C++ implementation, mathematical tests and independent NumPy positioning oracle were executed.
The CUDA implementation is delivered as \textbf{source targeting SM\_120}. CUDA compilation, GPU execution

The selected application is receive-only positioning and local geometric queries from prepared observations.
The output is an estimated position/clock state and diagnostics, not a route, flight-control command or actuator message.

The runtime has two GPU kernels: independent per-epoch positioning, then enrichment of the completed solutions.

\mathcal E_{3.6.1.5}:(\mathcal O_k,M_k,z_k^{(0)},\Theta)\longmapsto(\hat z_k,D_k).

\section{The new satnav observation model / SN1}
The supplied sources define geometry, state and operators; they do not give a GNSS pseudorange model.
SN1 adds the standard prepared-code positioning relation, using satellite positions and corrected observations
that share a reception-time frame. [N1, N2]
\begin{equation}\label{eq:observation}
P_i^*=\|\mathbf s_i-\mathbf r\|+b+\varepsilon_i,
\qquad b=c\,\delta t_r,\quad i\in\mathcal A.
\end{equation}
Here $\mathcal A$ is the explicitly selected satellite-slot set, not a searched target set.
The input has independent positive standard deviations $\sigma_i$ and weights $w_i=1/\sigma_i^2$.
The selected state minimizes
\begin{equation}
J(\mathbf r,b)=\sum_{i\in\mathcal A}\frac{[P_i^*-(\|\mathbf s_i-\mathbf r\|+b)]^2}{\sigma_i^2}.
\end{equation}
This weighted estimator is the new specialization, not a replacement for an ASA or UGTS definition. [N3]

\subsection{What ``corrected'' means}
A conventional raw code equation contains satellite clock, propagation and signal-dependent terms.
This interface places the modeled nonreceiver-clock terms on the data side:
\begin{equation}
P_i^*=P_i+c\delta t_{s,i}-T_i-I_i-d_{{\rm code},i}.
\end{equation}
The signs and particular signal corrections must match the upstream processor's convention.
The kernel does not apply a second copy of a correction that its input has already incorporated. [N1]

The satellite location is evaluated for emission and expressed in the ECEF frame tied to reception.
Those epochs are different. Earth rotation during propagation is part of the upstream coordinate
preparation; a satellite location at reception is not silently substituted for its emission location. [N2]

\subsection{Model dimension}
There are four unknowns: three position components and one receiver-clock bias. At least four independent
selected observations are required. One clock-bias family is assumed. Unresolved inter-system or inter-signal
offsets need additional unknowns or upstream corrections; packing them into a common bitset does not remove
the extra parameters.

The current code handles prepared code observations. It does not decode a navigation message, acquire an RF
signal or resolve carrier-phase ambiguities. That makes its input contract precise and its positioning calculation
usable with an upstream observation exporter.
\clearpage

\section{Reference frame and time}
The selected terrestrial frame is ECEF, with a local East--North--Up frame anchored at a supplied ellipsoidal
latitude $\varphi_0$, longitude $\lambda_0$ and height $h_0$. SN1 uses the WGS84 ellipsoid constants
$a=6378137\,\mathrm m$ and $1/f=298.257223563$. [N4, N5]
\begin{equation}
N(\varphi)=\frac a{\sqrt{1-e^2\sin^2\varphi}},\qquad e^2=f(2-f),
\end{equation}
\begin{equation}
\mathbf r_0=\begin{pmatrix}(N+h_0)\cos\varphi_0\cos\lambda_0\\
(N+h_0)\cos\varphi_0\sin\lambda_0\\(N(1-e^2)+h_0)\sin\varphi_0\end{pmatrix}.
\end{equation}
The local coordinate is $\mathbf p=R_{ENU}(\mathbf r-\mathbf r_0)$, with
\begin{equation}
R_{ENU}=\begin{pmatrix}
-\sin\lambda_0&\cos\lambda_0&0\\
-\cos\lambda_0\sin\varphi_0&-\sin\lambda_0\sin\varphi_0&\cos\varphi_0\\
\cos\lambda_0\cos\varphi_0&\sin\lambda_0\cos\varphi_0&\sin\varphi_0
\end{pmatrix}.
\end{equation}
The transformation is an orthonormal rotation of a translated vector. The geodetic Up vector is normal to
the chosen ellipsoid at the anchor; it is not generally the geocentric radial vector. [N4]

\subsection{Three dimensions are retained}
The local spatial log chart uses only $(E,N)$, while $U$ remains a separate metre-valued field.
The chart is a view/index of a solved three-dimensional point, not an assertion that the entire point is encoded
by two scalars. A change of anchor changes the local view without changing the underlying ECEF solution.

\subsection{One time scale per batch}
The \code{tick\_ms} input is an absolute, monotonically increasing GPST millisecond tick under the declared
common origin. It is not UTC, and no leap-second conversion is inferred by this CSV reader.
The key's 14-bit time coordinate uses \code{tick\_ms mod 16384}; the full tick is retained in every output.
Repeated modular time values are therefore not mistaken for identical epochs.

The numerical clock bias $b$ is a separate unknown. Dividing $b$ by $c=299792458\,\mathrm{m/s}$ yields
seconds of receiver offset under Eq.~\eqref{eq:observation}; it does not alter the epoch identifier or the hinge angle.
\clearpage

\section{Prepared input and aTOMos observation words}
The runnable profile assigns one bit to each of at most 32 observation slots in an epoch.
Let $V=(1\ll m)-1$ for $m<32$, or all 32 bits for $m=32$. The support word is $X=V$ because every
present record has a declared slot; quality selection is supplied by the ASA/NA masks.
\begin{align}
A&=X\land M_{\rm ASA}\land V,& N&=A\land M_{\rm NA},\\
H&=\pop(N\land M_{\partial}),&Y&=\begin{cases}0,&H>0,\\N,&H=0.\end{cases}
\end{align}
The active satellite set is $\mathcal A=\{i:Y_i=1\}$. This is the retained whole-word rule, applied to a
new \emph{observation-slot dictionary}. \aRef\newprofile

\subsection{Exact semantic preservation}
A boundary intersection clears the \emph{whole selected word}; it does not merely clear the intersecting bit.
A user-supplied observation exclusion therefore belongs in the ASA or NA mask when it is intended to remove
only that observation. The implementation does not silently change the boundary operator to make a GNSS
quality-control algorithm out of it.

Epochs with $H>0$ return \code{whole\_word\_absorbed}. Those with fewer than four surviving observations return
\code{insufficient\_observations}. More than four slots does not guarantee rank; the solver separately checks
the geometry's numerical rank.

\subsection{CSV binding}
An epoch file supplies full time, initial four-state estimate, hinge angle, masks, J/K bits and the three-bit
blend encoding. An observation file supplies epoch ID, contiguous slot, unique satellite ID, three satellite
coordinates, corrected code and sigma. A row referencing an absent epoch, duplicate slot, nonfinite number
or a nonpositive sigma is an input error, not a missing observation silently set to zero.

The files represent prepared, receive-only observations. There is no hidden radio configuration, antenna
command or route generator in the parser. The absent physical frontend from the aTOMos 3.6.1 source-profile
obligations is not claimed to have been completed merely by adding a CSV interface.
\clearpage

\section{Position solution by streaming weighted QR}
At estimate $(\mathbf r^{(k)},b^{(k)})$, write
\begin{equation}
d_i^{(k)}=\|\mathbf r^{(k)}-\mathbf s_i\|,
\quad v_i^{(k)}=P_i^*-d_i^{(k)}-b^{(k)},
\end{equation}
\begin{equation}
g_i^{(k)}=\left[\frac{x^{(k)}-s_{ix}}{d_i^{(k)}},
\frac{y^{(k)}-s_{iy}}{d_i^{(k)}},
\frac{z^{(k)}-s_{iz}}{d_i^{(k)}},1\right].
\end{equation}
The whitened row and right-hand side are $a_i=g_i/\sigma_i$ and $\tilde v_i=v_i/\sigma_i$.
The update minimizes $\|A\Delta z-\tilde v\|_2^2$. [N1, N3]

\subsection{Bounded per-thread workspace}
The implementation inserts each selected row into an upper-triangular $4\times4$ factor $R$ and a
four-element transformed right-hand side. For a diagonal element $r_{kk}$ and incoming component $a_k$,
\begin{equation}
\gamma=\operatorname{hypot}(r_{kk},a_k),\quad c=r_{kk}/\gamma,\quad s=a_k/\gamma.
\end{equation}
The Givens rotation replaces the two rows so the new incoming component is zero. The same rotation is
applied to the right-hand side. A zero pair is skipped. Repeating this for all selected rows produces the
least-squares triangular system without forming normal equations for the update.

Back substitution solves $R\Delta z=z_R$, then the four-state estimate is updated. The loop stops when
both the position-increment norm and the clock-increment magnitude are no greater than $10^{-4}$ m.
The profile uses at most 20 iterations; exceeding this returns a distinct \code{iteration\_limit} status.

\subsection{Rank and finite arithmetic}
A factor is treated as numerically rank deficient if a diagonal magnitude is no more than
$10^{-11}$ times the largest diagonal, or if a required factor is nonfinite. The four-state units are balanced
because the clock unknown is in metres. This diagonal test is a specified numerical criterion, not a
rank-revealing pivot theorem for every possible geometry.

Satellite coordinates and corrected observations remain fixed during one solve. Only the receiver state
is iterated. The coordinate-preparation convention in Section 3 therefore matters; an unmodeled change of
satellite epoch is not repaired by extra iterations.
\clearpage

\section{Residuals and formal uncertainty}
After the final iteration, the implementation rebuilds the whitened geometry at the returned state.
It reports
\begin{equation}
\mathrm{RMS}=\sqrt{\frac1m\sum_i v_i^2},\qquad
\chi^2=\sum_i(v_i/\sigma_i)^2.
\end{equation}
The latter is a normalized residual sum; no unknown global noise scale is silently substituted for the input
sigmas. With four fitted parameters the nominal residual degrees of freedom are $m-4$ when the selected
linearized geometry is full rank.

For independent observation errors with the supplied variances, the formal linearized covariance is
\begin{equation}
P=(A^TA)^{-1}=R^{-1}R^{-T}.
\end{equation}
The code solves four triangular systems to construct its diagonal and reports the four formal standard
deviations. These values refer to the stated observation model, chosen weights and local linearization;
they are not deterministic support radii or a claim that all real errors were modeled. [N3]

\subsection{No implicit robust reweighting}
The baseline does not discard a large residual automatically, perform subset solution separation or invent
new observation sigmas. The supplied ASA/NA masks and sigmas are explicit inputs. A new robust-estimation
profile would identify its own estimator and tests instead of altering the result under the same profile tag.

\subsection{Positioning result states}
\par\small

\textbf{State} & \textbf{Meaning}\\\midrule
\code{ok} & Converged four-state solution with finite full-rank final geometry.\\
\code{insufficient\_observations} & Fewer than four selected observations.\\
\code{whole\_word\_absorbed} & The retained boundary rule clears the selected word.\\
\code{rank\_deficient} & Geometry fails the stated numerical rank criterion.\\

\code{nan} together with an explicit status, not misrepresented by a valid-looking zero coordinate.

\section{JK and encoded blend inside the satnav record}
The aTOMos sequential bit operator remains
\begin{equation}
q^+=(J\land\neg q)\lor(\neg K\land q),\qquad q,J,K\in\B.
\end{equation}
\begin{center}
\begin{tabular}{@{}cccl@{}}\toprule
$J$&$K$&$q^+$&\textbf{Meaning}\\\midrule
0&0&$q$&Hold\\1&0&1&Set\\0&1&0&Reset\\1&1&$1-q$&Toggle\\\bottomrule
\end{tabular}
\end{center}
The prepared epoch supplies its own \code{q\_before}, \code{j} and \code{k}. Batch positioning is parallel across
epochs and does not reconstruct an unknown control history. A stateful caller can supply successive before-states;
the CSV explicitly states each epoch's bit inputs. \aRef

The encoded circle-plus result remains
\begin{equation}
s_{\rm blend}=n_b\oplus a_b\oplus\beta_b.
\end{equation}
The file stores these three bits in the integer \code{blend\_bits}; its high-to-low bits are north, axis and
kinematic. Neither this parity nor the JK state is inferred from a position error or an OTAN2 residual.

\subsection{Retained independence}
A solver can return a nonzero JK state while its observation word is absorbed. Those are different results
with different operands. Likewise, a key can be unavailable because a valid position lies outside the local
chart, while the ECEF solution itself remains valid.

The broader aTOMos alignment, sweep-limit and active-fringe predicates remain independently typed roles.
The selected SN1 executable uses explicit observation masks rather than a fabricated beam-alignment
classifier. Its geometric classes annotate the estimated receiver point. No satellite-navigation number is
automatically recast as a set/reset command or a source-defined physical fringe measurement.

\subsection{Nucleus and state}
The earlier engine's identity/state distinction remains conceptually compatible: a receiver/session identifier
is not a coordinate or a mask. In the selected plain-record runtime, epoch IDs and full time supply the needed
association without adding a content-addressed ledger. The author attribution is carried in this edition's
identity fields, not used as an executable permission token.

\section{UGTS finite cone and paired supports}
The conjoined geometry retains the finite right circular cone defined by slant $T_c>0$ and half-angle
$0<\alpha_c<\pi/2$:
\begin{equation}
h=T_c\cos\alpha_c,\qquad R=T_c\sin\alpha_c.
\end{equation}
For query $\mathbf p$, apex $\mathbf c$ and unit axis $\mathbf a$, use
\begin{equation}
z=\mathbf a\cdot(\mathbf p-\mathbf c),\qquad
q=\|(\mathbf p-\mathbf c)-z\mathbf a\|.
\end{equation}
The Euclidean signed distance is the signed distance of $(q,z)$ to the filled meridian triangle
$(0,0),(R,h),(-R,h)$, negative for the cone interior. The implementation takes the minimum distance to the
three boundary segments and assigns the sign using $0\le z\le h$ and $qh\le zR$. This realizes the exact
primitive defined in the supplied document. \uRef{\S3.1; Figure 2 on PDF p.5}

The two spherical relations are separately evaluated:
\begin{equation}
f_L(\mathbf p)=\|\mathbf p-\mathbf c_L\|-R_L,\qquad
f_R(\mathbf p)=\|\mathbf p-\mathbf c_R\|-R_R.
\end{equation}
The two-bit output retains membership in each sphere and their overlap. It does not collapse two independent
supports into a biological or sensor claim. \uRef{\S3.2}

\subsection{SN1 local-support example}
The executable uses a declared local example: cone apex $(0,0,-100)$ m, Up axis, slant 1000 m and half-angle
$\pi/3$; spheres centered at $(0,0,0)$ and $(200,0,0)$ m with radius 500 m. The point-relation margin is
0.001 m. These are editable \textbf{SN1 fixture values}, not numerical antenna parameters found in either source.

The relation class is interior when the residual is below $-\epsilon_g$, exterior above $+\epsilon_g$, and
margin-band otherwise. The underlying residual remains in the output. This evaluates a geometric relation at
the estimated point; its class does not feed back into the position solve or alter J/K inputs.

\subsection{One exact check}
For $T_c=2$, $\alpha_c=\pi/6$, zero apex, Up axis and $\mathbf p=(0.15,0,0.6)$, the side residual is
$0.15\cos(\pi/6)-0.6\sin(\pi/6)=-0.1700961894\ldots$. This reproduces the source's displayed interior value
with explicitly stated query parameters and is checked in the C++ tests.

\section{Translational sweep and interval algebra}
For a fixed-orientation cone and finite translation $s(u)$, the UGTS sweep relation is
\begin{equation}
F(\mathbf p)=\inf_{u\in[0,1]}d_C(\mathbf p-s(u)).
\end{equation}
For a linear path of length $L$ and $n\ge2$ equally spaced samples, let $m_n$ be the minimum sampled value.
The retained interval is
\begin{equation}\label{eq:sweep}
m_n-\frac{L}{2(n-1)}\le F(\mathbf p)\le m_n.
\end{equation}
The closest continuous parameter lies within half a sample step of some sampled parameter, and signed
distance under translation is 1-Lipschitz. This gives the bound in Eq.~\eqref{eq:sweep}. \uRef{\S4}

A zero-length sweep has zero interval width. The radius $L/[2(n-1)]$ decreases as $n$ grows. The numerical
intervals from \emph{arbitrary nonnested} sample sets need not themselves nest. Nested sampling or intersection
with previously established intervals supplies a nested certificate sequence. This distinction makes the source's
sample-density language explicit rather than silently strengthening the theorem.

Rotating cones require additional information beyond this translation proof. The conjoined helper implements
the stated fixed-orientation translational relation, not an unprovided general rotational envelope.

\subsection{The two jitter intervals are different objects}
UGTS defines $f_j=f+\epsilon_j\sigma$, $\sigma\in\{-1,+1\}$. Its page-5 display equates intervals centered
on $f_j$ and $f$. In general those intervals are not equal. This edition retains their distinct meanings:
\begin{equation}
I_0=[f-\epsilon_j,f+\epsilon_j],\qquad
I_j=[f_j-\epsilon_j,f_j+\epsilon_j],\qquad f=f_j-\epsilon_j\sigma.
\end{equation}
$I_0$ is a nominal uncertainty interval; $I_j$ contains the unperturbed $f$ when only the signed bounded
modulation is known. For $\epsilon_j>0$, their centers differ. The independent helper and regression test
preserve this distinction explicitly. \uRef{\S6}

SN1 does not add jitter to code observations. Reported measurement sigma, numerical relation margin and
an optional synthetic field-jitter amplitude are three separate inputs with different meanings. Removing their
type distinction would change the model rather than simplify it.

\section{Local log-polar metric and kinematics}
The conjoined local chart uses
\begin{equation}
r=\sqrt{E^2+N^2},\quad \rho=\ln(r/r_0),\quad\theta=\operatorname{atan2}(N,E).
\end{equation}
SN1 chooses $r_0=10{,}000$ m and an explicit origin core $r<0.01$ m. \emph{Theta is east-zero and
counterclockwise in the EN plane}; it is not a north-zero navigation bearing. Up remains separately recorded.
For packing, $\rho$ must also lie in $[-20,0]$; no clamp silently turns an out-of-range solution into a valid key.
\newprofile

The retained UGTS metric, exact finite radial step and Jacobian are
\begin{align}
ds^2&=r^2(d\rho^2+d\theta^2),& \Delta r&=r\,\operatorname{expm1}(\Delta\rho),\\
J&=r\begin{pmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{pmatrix}.&&
\end{align}
The approximation $r\Delta\rho$ is only the first-order expansion of the exact radial change.
The origin is an explicit core case rather than a direction manufactured by $\ln0$. \uRef{\S5}

For supplied coordinate rates,
\begin{align}
\mathbf v&=r(\dot\rho\,\mathbf e_r+\dot\theta\,\mathbf e_\theta),\\
\mathbf a&=r[(\ddot\rho+\dot\rho^2-\dot\theta^2)\mathbf e_r+
(\ddot\theta+2\dot\rho\dot\theta)\mathbf e_\theta].
\end{align}
These formulas are retained and tested in the independent geometry helpers. The code-only positioning
solver does not infer a physical acceleration model or claim a velocity estimate from a single epoch.

\subsection{Gradient and field versus coordinate effect}
For chart derivatives $(f_\rho,f_\theta)$,
$\nabla f=(f_\rho\mathbf e_r+f_\theta\mathbf e_\theta)/r$.
This is a coordinate transformation. It does not automatically turn a physical force into $e^{-\rho}$ times
some other vector. A mechanics model remains a separate definition, as UGTS explicitly states.

The local chart serves packing, differential observation and query geometry. The global receiver coordinates
remain the three ECEF values computed from the observations. No Klein wrap or grammar step changes those
coordinates during the satnav solve.

\section{OTAN2, consecutive samples and invariant meanings}
The literal operator retained from aTOMos is
\begin{equation}
\ot_s(\Delta\theta,\Delta\rho)=\arctan(\Delta\theta/\Delta\rho),\qquad\Delta\rho\ne0,
\end{equation}
\begin{equation}
e_s=\ot_s-\alpha_r.
\end{equation}
The output stores the source orientation and raw relative residual. It also stores the separately named
completion $e_d=\wrap_{2\pi}(\operatorname{atan2}(\Delta\theta,\Delta\rho)-\alpha_r)$. Neither quantity is a
position estimate, satellite code phase or automatically an arrival direction. \aRef

The executable uses consecutive solved epochs in one fixed local chart. Its declared increment policy is
\begin{equation}
\Delta\rho=\rho_k-\rho_{k-1},\qquad
\Delta\theta=\wrap_{2\pi}(\theta_k-\theta_{k-1}).
\end{equation}
This is a \emph{principal-difference} profile. It is not recovery of arbitrary physical winding from two samples.
A failed solve or out-of-chart previous sample leaves the differential observation unavailable.

\section{Full time, phase, winding and topology}
UGTS keeps linear time and defines a phase clock with reference $X_0$ and period $P$:
\begin{equation}
u=(X-X_0)/P,\qquad w=\lfloor u\rfloor,\qquad\psi=u-w\in[0,1).
\end{equation}
Winding $w$ distinguishes repeated phase positions. Its source example uses reference 1135, tick 1920 and
period 256, producing $w=3$ and $\psi=0.06640625$. The units belong to that profile and are not universal
satellite-navigation constants. \uRef{\S7}

SN1 retains the full absolute millisecond tick and packs only its remainder modulo $2^{14}$. A modular
key can repeat after 16.384 s with this tick unit; the absolute epoch does not repeat. The compact word is
therefore an address component, not a complete time history.

\subsection{Two distinct topology profiles}
On an odd radial wrap the source half-turn profile is
\begin{equation}
(\rho,\theta,\phi_h,o)\mapsto(\rho',\theta+\pi,-\phi_h,-o).
\end{equation}
The reflective Klein profile instead uses
\begin{equation}
(\rho,\theta,\phi_h,o)\mapsto(\rho',\pi-\theta,-\phi_h,-o).
\end{equation}
The first map rotates the base angular circle; the second reverses its orientation. Both are preserved with
separate tags. The reflective tangent map also negates angular and hinge tangent components. A chart
transition is not a physical torque impulse. \uRef{\S8; Figure 4 on PDF p.8}

\subsection{Selection in this specialization}
The live positioning/enrichment path uses a bounded local annular chart. It does \emph{not} apply either
topological wrap to global ECEF coordinates or fold a receiver to a different Earth location. The two maps
remain executable mathematical helpers for the retained UGTS state relations.

The source's half-open wrapping interval and the inclusive endpoint quantizer are distinct contracts.
Wrapping $\rho=0$ in $[-20,0)$ produces a wrap event; quantizing $\rho=0$ in the source's closed key range
produces the maximum radial index. The profile selection determines which operation is being performed.

\section{Radix refinement, grammar and constraint calculus}
A key prefix is a radix-trie address. Appending $b$ gives $p'=(p\ll1)\lor b$ and fixes the next bit in the
selected schedule. The corresponding integer-field interval narrows; a decoded physical coordinate is not
necessarily halved. The independent prefix helper checks that no field interval widens after refinement.
\uRef{\S11}

The retained bounded binary grammar has the schematic production
\begin{equation}
F(T_c)\Rightarrow F(T_c/2)\,[\,\pm\phi_h\ F(T_c/2)\,]J(\Delta r).
\end{equation}
Its depth-4 symbolic example has 16 forward symbols and 76 total tokens. The code checks explicit finite
depth/symbol capacity and balances the brackets. The turn sign is affected by the declared chirality profile.
A supplied 12-bit grammar-state code and the 12-bit hinge quantizer are separate objects; this implementation
does not invent the absent codebook mapping a grammar to the source's state word 1058. \uRef{\S10}

\subsection{Hinge and missing shackle}
The hinge state is $(\phi_h,\dot\phi_h,\ddot\phi_h)$. A mechanical model can supply coefficients for
$\tau=I\ddot\phi_h+c\dot\phi_h+k\phi_h$; without those parameters, acceleration is not renamed torque.
For a supplied velocity constraint $A(q)\dot q=0$, deleting a row gives the exact freedom change
\begin{equation}
\Delta d=\operatorname{nullity}(A')-\operatorname{nullity}(A).
\end{equation}
For the two independent coordinate rows in the source example, removal raises nullity from one to two.
Removing a redundant row need not change nullity. Both cases are tested independently. \uRef{\S9}

For a regular zero-surface normal $\mathbf n$, the tangent projector is
$P_T=I-\mathbf n\mathbf n^T$ when $\|\mathbf n\|=1$. It preserves first-order tangency, not exact finite-step
surface membership without further integration/projection.

These retained UGTS mechanisms are part of the conjoined mathematical package. They do not generate
satellite ephemerides, commanded routes or an unprovided physical motion model. The SN1 positioning path
uses measurements, not a grammar expansion, to determine receiver coordinates.

\section{CUDA kernels and observation residency}
The shared implementation is in \code{include/atomos/nav.hpp}. It is compiled as ordinary C++ for the CPU
and as host/device code for CUDA. The GPU backend contains a positioning kernel and an enrichment kernel.
One CUDA thread solves one independent epoch, with up to 32 observations and a small local QR workspace.

The GPU observation representation is a structure of arrays with five components:
$s_x,s_y,s_z,P^*,\sigma$. For chunk size $N$, the linear element address is
\begin{equation}
\operatorname{index}(c,i,k)=(32c+i)N+k.
\end{equation}
At a fixed satellite slot and component, neighboring threads read neighboring epochs. Empty trailing slots
are initialized but never selected beyond the declared count.

\subsection{Two input-read implementations}
The global path directly loads binary64 values. The texture path binds the same bytes to an integer-pair
linear texture resource, reads \code{int2}, then reconstructs the double with
\code{\_\_hiloint2double(high,low)}. This preserves all 64 input bits instead of converting Earth-scale ECEF
positions to float32. The texture descriptor uses element-type reads; integer fetches do not interpolate
coordinates or observation values. [H4]

The texture is a read interface for data. Its creation does not pin all inputs in a hardware cache, and it does
not place native instructions in a texture. All read paths execute the same QR and enrichment definitions.

\subsection{Kernel boundaries}
The solve kernel completes before enrichment in the same CUDA stream. Enrichment accesses the preceding
result within the chunk, or receives the previous chunk's final solution and metadata by value. This explicit
carry prevents a false reset of OTAN2 at every chunk boundary.

All CUDA allocation, copy, launch and synchronization results are checked. A requested GPU run does not
silently substitute CPU work while reporting a GPU backend. The supplied device-review script compares
both read paths and chunk sizes 1, 7 and 8192 against the independent reference.

\section{Recovery and positioning invariants}
\begin{theorem}[aTOMos projection]
Projection of the conjoined computation onto its ASA, NA, hit count and output-mask fields gives the
original word rule on the declared observation dictionary. Projection onto JK and encoded blend gives
the original bit equations on their explicit inputs.
\end{theorem}
\begin{proof}
Those calculations use exactly the retained operators with the supplied mask and bit operands. The numerical
positioning and UGTS enrichment stages write separate fields and do not change the operands. Dropping
those added fields therefore recovers the original results.
\end{proof}

\begin{proposition}[Clock-shift relation]
Adding a common $\Delta b$ to every prepared code observation leaves the position minimizer unchanged
and increases the receiver-clock minimizer by $\Delta b$, subject to the same solution branch and convergence.
\end{proposition}
\begin{proof}
Replacing $P_i^*$ by $P_i^*+\Delta b$ and $b$ by $b+\Delta b$ leaves every residual in the objective unchanged.
Thus the objective is translated only in its clock coordinate. The supplied regression checks this relation.
\end{proof}

\begin{proposition}[Common weight-scale relation]
Multiplying all observation sigmas by $c>0$ preserves the minimizing state and multiplies its formal
standard deviations by $c$ under the same linearized geometry.
\end{proposition}
\begin{proof}
The objective is multiplied by $1/c^2$, which preserves its minimizer. The whitened matrix is divided by
$c$, so its information matrix is divided by $c^2$ and covariance multiplied by $c^2$.
\end{proof}

Observation permutation, with slot masks remapped consistently, preserves the mathematical objective.
Finite QR accumulation can introduce round-off differences, so the cross-implementation comparison uses a
stated numerical tolerance rather than claiming identical floating-point evaluation order.

\subsection{Chart/query isolation}
Changing only the local anchor, support region or OTAN2 reference must not change the computed ECEF
position/clock. Changing a query profile can change the local result and packed key, but not the upstream
measurements. The code separates these inputs, and the tests check the no-mutation property.
\clearpage

The output includes the original epoch/tick, solver status, iteration count, selected count, all ASA fields,
JK/blend outputs, four estimated state values, RMS, normalized residual sum, four formal sigmas, local ENU,
log chart, OTAN2 fields, relation values/classes and both integer keys.

\subsection{Numerical domain markers}
Chart status zero means the compact key is defined. Status one means no solved position; two identifies the
explicit local origin core; three denotes an out-of-chart radial or hinge value. A zero key with nonzero chart
status is not a meaningful packed position.

OTAN2 status zero means the literal source ratio is defined. One means no eligible preceding sample; two is
zero increment; three is a zero literal denominator; four is a numerical-range condition. In a pure-angular
case the separate directed residual can still be defined. These fields are not silently unified into a fake zero.

\subsection{Embedding}
The shared library exposes \code{solve}, \code{enrich}, \code{cpu\_run} and, in a CUDA build,
\code{cuda\_run}. A downstream application can use the estimated receiver position as data. This package
contains no vehicle-control message encoder. Input preparation remains responsible for ephemerides,
clock/propagation corrections, signal definitions and the common reception-time coordinate frame.

\subsection{What is source-derived and what is new}
The aTOMos masks, JK/encoded blend, literal OTAN2 and its named completion are retained from the 3.6.1
project contract. The UGTS geometry, metric, topology separation, grammar/constraint relations and key
layouts are derived from the supplied SCLP document and are identified by its section numbers.

SN1 adds the measurement model, weighted receiver-position/clock estimator, chosen local WGS84 anchor,
prepared CSV schema and GPU mapping. Its numerical fixture parameters are labelled examples. The
jitter-interval equality and nonnested sweep-density statement are explicitly distinguished where the printed
source would otherwise be carried into an incorrect mathematical equality.

The supplied PDF describes an original UGTS archive with 153 prior tests. That archive was not supplied here;
its count is not reported as a new result. This package's actual tests and CPU builds are the ones summarized
in this volume. The earlier aTOMos master PDF likewise is retained through the project's stated contract,
not presented as a newly mounted file that was compiled as source.
