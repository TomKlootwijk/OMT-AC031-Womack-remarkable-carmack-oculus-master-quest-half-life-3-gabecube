2.1 What is carried forward
The inherited formal contracts include the four-word ASA result; complete-mask opt-in; the three
separate blend predicates; the JK truth table; the literal ratio and directed-completion distinction;
explicit winding/frame metadata; and the six invariant/projection laws. These are restated in full
rather than incorporated only by a reference to a previous PDF.
The older source sometimes assigns different meanings to the same symbol or supplies alternative
operations. Both are retained as named variants or namespaces. For example, raw-word XOR and
OR splitting remain distinct; a bitmask is not silently renamed as a coordinate key; and the three
meanings of “State 1” in C remain three fields. [A, pp. 10–14, 33–37][C, pp. 2–5]
2.2 Source, completion and master assembly
An equation quoted from O is marked as its source expression. A four-quadrant completion is
inherited from J361 and named as such. A new transaction order in M1 is a declared assembly
choice. This distinction prevents consolidation from quietly changing the meanings of earlier
terms. [J361, pp. 8–12][I2, pp. 4–11]
The new master order states how documented components share a snapshot and a commit. It is
not presented as a recovered implementation ABI of the historicalv3.6.1 target. Required but
unsupplied data, including a B-profile, actual eigenmatrix, optical transfer table or J/K input
policy, remains an explicit configuration obligation. A parameterized engine is still one engine: its
unspecified parameters must be supplied before the operations depending on them are enabled.

28 Computational simulation and its stated scope
Theorem 28.1(Machine simulation in the U profile). Assume logical integer addresses and enough
storage for each finite execution prefix. Every deterministic machine with finite control and finite alphabet
as defined in Section 27 can be encoded so that the U interpreter preserves its tape, head, control state and
halting behavior after each defined transition.
Proof. Number the finite symbols and states. Store the machine’s transition table unchanged under
those codes. Pack each initial symbol into its𝑘-bit tape block, and copy its initial head and control
state.
Use the invariant that every decoded block equals the corresponding machine symbol and that the
head and control state agree. It holds initially. If it holds before a step, the interpreter reads the
same symbol, selects the same transition, overwrites exactly the current symbol block, and applies
the same head and control updates. Distinct fixed-size blocks are disjoint, so other symbols are
unchanged. The invariant holds after the step. Induction gives every finite prefix and hence the
same entry into a halt state. □
This is the retained meaning of programmable computational universality. It relies on addressable
state and a supplied transition table. A finite wrapped polar dictionary cannot replace an
unbounded logical tape without eventually aliasing distinct logical cells.

stop is therefore carried as a status in the engine’s provenance, not mislabeled as an abstract halt or
as completion of an arbitrary computation.
